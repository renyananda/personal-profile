# 🌐 Personal Portfolio Website

Proyek ini merupakan hasil slicing desain dari Figma menjadi website menggunakan React JS dan Tailwind CSS.  
Website ini menampilkan profil pribadi, skills, portofolio, dan kontak dengan desain yang responsif untuk mobile, tablet, dan desktop.

---

## 🧩 Struktur Halaman
- **Navbar** – navigasi dengan smooth scroll ke setiap section  
- **Hero Section** – profil utama dan deskripsi singkat  
- **About Section** – informasi singkat tentang diri  
- **Skills Section** – daftar kemampuan dengan ikon  
- **Portfolio Section** – galeri proyek dengan kategori warna  
- **Contact Section** – form kontak dan sosial media  

---

## 📱 Tampilan Responsif
Website ini dirancang agar tampil optimal di berbagai ukuran layar:
- `sm:` Mobile  
- `md:` Tablet  
- `lg:` Desktop
